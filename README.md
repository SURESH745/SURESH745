## 🏗️ Flagship Enterprise Solutions

### 🛡️ [Intelligent Claims Lakehouse: Insurance 2.0](https://github.com/SURESH745/Intelligent_Claims_Lakehouse_Insurance_Domain)
**The Challenge:** Legacy batch systems were causing 7-day delays in insurance claim settlements.
**The Architecture:**
* Built a **Real-time CDC pipeline** using Lakeflow Connect to sync on-prem SQL Server with Azure Databricks.
* Engineered a **Medallion DLT (Delta Live Tables)** architecture with built-in quality "Expectations" to prevent data corruption.
* **Architectural Win:** Achieved **70% claim auto-approval** by integrating real-time damage classification directly into the Gold layer logic.
* **Impact:** Reduced processing latency by **98%** (from 7 days to <5 minutes).

### 🤖 [Enterprise GenAI Engine: Modular RAG](https://github.com/SURESH745/Retrieval-Augmented-Generation-RAG-project)
**The Challenge:** LLM hallucinations in banking domains were creating high-risk misinformation.
**The Architecture:**
* Architected a modular **Retrieval-Augmented Generation** engine featuring **Semantic Chunking** and Hybrid Search.
* Implemented **persistent vector indexing** to minimize cold-start latency and reduce embedding API costs by 35%.
* **Architectural Win:** Developed a proprietary `AdvancedRAGPipeline` class that enforces **Context Grounding**, ensuring 100% factual accuracy with source-linked citations.
* **Impact:** Delivered a production-ready knowledge agent capable of sub-second retrieval across 10,000+ technical assets.

### 📈 [Banking MLOps Factory: Churn Prediction](https://github.com/SURESH745/MLOps-Pipeline-for-Banking-Domain)
**The Challenge:** ML models were stagnating in notebooks with no path to production or monitoring.
**The Architecture:**
* Deployed an end-to-end **MLOps Lifecycle** using MLflow for experiment tracking and Prefect for scheduling.
* Integrated **Evidently AI** for automated **Data Drift & Concept Drift** monitoring.
* **Architectural Win:** Automated the retraining loop; the system now self-corrects when model precision drops below 85% without manual intervention.
* **Impact:** Boosted model deployment velocity by **80%**.
